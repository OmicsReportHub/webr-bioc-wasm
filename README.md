# webR Bioconductor Wasm Packages

This repository builds and hosts a webR-compatible R package binary repository for optional browser-side RNA-seq analysis modules.

The companion report app is expected to live in a separate repository:

```text
OmicsReportHub/rnaseq-report
OmicsReportHub/webr-bioc-wasm
```

## What this repo does

- Uses `r-wasm/actions` to build R packages for WebAssembly.
- Publishes a CRAN-like binary repository to GitHub Pages.
- Lets the static RNA-seq report install optional R packages with `webr::install()`.

## Starter package list

The `packages` file starts with a small RNA-seq-friendly set:

```text
bioc::limma
bioc::edgeR
cran::ggplot2
cran::matrixStats
cran::jsonlite
cran::Matrix
```

`DESeq2` is intentionally not in the default `packages` file because it has a larger dependency stack. Try `limma` and `edgeR` first, then move packages from `packages-experimental` into `packages` once the build path is working.

## Create and push this repo

From the parent folder containing `webr-bioc-wasm/`:

```bash
ORG=OmicsReportHub

git -C webr-bioc-wasm init
git -C webr-bioc-wasm add .
git -C webr-bioc-wasm commit -m "Initial webR Bioconductor wasm package repo"

gh repo create "$ORG/webr-bioc-wasm" --public --source=webr-bioc-wasm --push
```

## Enable GitHub Pages

1. Go to repository **Settings > Pages**.
2. Under **Build and deployment**, select **GitHub Actions**.
3. Run the **Build and deploy wasm R package repository** workflow.

After the workflow succeeds, the package repo should be available at:

```text
https://YOUR_ORG.github.io/webr-bioc-wasm/
```

Update the RNA-seq report's `assets/report_config.json`:

```json
{
  "webr": {
    "enabled": true,
    "baseUrl": "https://webr.r-wasm.org/latest/",
    "packageRepo": "https://YOUR_ORG.github.io/webr-bioc-wasm/"
  }
}
```

## Test from webR

In a webR session:

```r
options(repos = c(
  rnaseq = "https://YOUR_ORG.github.io/webr-bioc-wasm/",
  webr = "https://repo.r-wasm.org/"
))

webr::install(c("limma", "edgeR"))
library(limma)
library(edgeR)
```

## Important limitations

- webR can load R packages that have been precompiled for WebAssembly.
- Some Bioconductor packages or transitive dependencies may fail to build.
- Browser memory is limited compared with HPC/cloud environments.
- Production RNA-seq differential expression should be generated by the pipeline and displayed in the report; browser-side R should be an optional exploratory layer.
- Do not publish sensitive data or proprietary annotation assets to public GitHub Pages.

## Maintenance workflow

1. Edit `packages`.
2. Push to `main`.
3. Wait for GitHub Actions to build and deploy.
4. Test package installation from the RNA-seq report.
5. Pin your report release to a known package repo revision if reproducibility is critical.
